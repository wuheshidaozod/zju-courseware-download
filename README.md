# 学在浙大 · 下载课件（含 WPS 导出）

油猴（Tampermonkey）脚本：在学在浙大学习活动页加“下载课件”按钮。

- 老师开放下载的附件：走正常下载接口。
- 老师禁止下载、但开启了 WPS 在线预览的附件：参照 [zju-learning-assistant](https://github.com/PeiPei233/zju-learning-assistant) 走 WPS 预览导出协议（优先原文件，其次预览版 PDF）。

仅用于下载自己选修课程的课件。

## 安装

1. 浏览器安装 Tampermonkey。
2. 打开 `zju-courseware-download.user.js`，点 “Raw”，Tampermonkey 会提示安装。
